# Upper Respiratory Symptoms – Clinical Guide

A standalone clinical teaching guide with symptom assessment, condition search, reference information, Centor scoring, and quizzes.

## Run locally

Serve this directory with any static HTTP server, for example `python -m http.server 8000`.

## Deploy

Import this repository into Vercel, choose Other as the framework, and leave build and install commands empty. Serve the repository root. No API keys are required.

Clinical content is supplied by the original uploaded guide; deployment does not constitute clinical validation.
